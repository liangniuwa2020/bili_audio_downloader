# Bilibili 音频高保真下载 & 智能分轨/歌词助手

一款基于 **Python + CustomTkinter + Bilibili API / yt-dlp + FFmpeg** 构建的高颜值、功能强大的 B站 音频下载、自动分轨切片与同步歌词处理桌面工具。

---

## ✨ 核心特性

1. **🔗 智能 URL 解析与直通通道**:
   - 支持 B站 普通视频链接（`BV...` / `av...`）、多 P 视频链接（`?p=1`, `?p=2`）及 `b23.tv` 短链接。
   - 内置 **B站 Direct API 直速通道** + **yt-dlp 引擎** 双引擎机制，防封禁、抗 412 拦截，解析秒级响应。

2. **🎵 高保真 MP3 音频提取与 ID3 标签写入**:
   - 提取最高品质音轨，利用 FFmpeg 实时转换为 320kbps / 256kbps / 192kbps MP3。
   - 自动获取 UP 主、视频标题、最高清封面图片，使用 `mutagen` 写入标准 ID3 标签。

3. **✂️ 自动化时间轴/章节分轨切片**:
   - **多 P 视频**: 自动按分集拆分为 `P01_集名.mp3`, `P02_集名.mp3`。
   - **单视频章节分轨**: 自动提取 B站 视频章节 API 或解析视频简介中的时间戳（如 `00:00 歌曲A`, `03:45 歌曲B`），调用 FFmpeg 秒级无损切分为多首独立歌曲 MP3，并自动编号和命名。

4. **📝 歌词同步下载与时间轴截取**:
   - 自动获取 B站 官方 CC 字幕 / AI 字幕，转换为标准 `.lrc` 歌词文件。
   - **分轨歌词自动校准**: 针对切分后的每首歌曲，自动截取主歌词中对应的行，并将时间轴重置为 `[00:00.00]`，生成与该首歌曲完全对齐的专属 `.lrc` 文件。

5. **🎨 现代极简 Dark Mode 界面**:
   - 基于 CustomTkinter 打造，支持视网膜高清响应。
   - 提供视频封面预览、时长及字幕状态检测、章节 tracklist 预览清单、保存路径选择、进度条与实时控制台日志。

## 🚀 快速启动

### 1. 环境准备
系统需满足：
- **Python 3.10+** (推荐 3.13)
- **FFmpeg** (确保命令在系统环境变量 PATH 中可用)

安装 Python 依赖库：
```bash
pip install -r requirements.txt
```

### 2. 运行应用
```bash
python main.py
```

## 📖 使用指南

1. **输入网址**: 在顶部文本框中粘贴 B站 视频地址（如 `https://www.bilibili.com/video/BV1GJ411x7h7`）。
2. **解析页面**: 点击 **[解析页面]** 按钮，系统将自动抓取视频标题、UP主、封面、多P列表或简介中的时间轴章节，并在左侧展示分轨清单。
3. **选择选项**:
   - 设置保存路径（默认为 `~/Downloads/BiliMusic`）。
   - 选择 MP3 比特率（320kbps 最高 / 256kbps 极高 / 192kbps 标准）。
   - 勾选 `自动分割时间轴章节为独立 MP3 文件` 与 `同步下载与自动切分 LRC 歌词文件`。
4. **开始处理**: 点击 **[🚀 开始下载并处理]** 按钮，系统将自动进行音频下载、MP3 转换、歌词生成、ID3 标签写入与无损分轨切片。处理完成后可直接在保存目录中找到排版整齐的歌曲与 `.lrc` 文件。
